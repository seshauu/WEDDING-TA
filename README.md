# Tamilarasan & Afrin, beach-themed reception invite

Deploy: push this folder to GitHub, then vercel.com > Add New Project > import > Deploy. No build settings.

Optional files (the page picks them up automatically):
- images/couple.png   caricature of the couple (transparent PNG, ~900px tall). Replaces the drawn couple.
- the couple frames show their initials
- audio/music.mp3     your song; plays when guests open the invitation (a soft built-in tune plays if this file is missing)

Settings: top of the <script> (times, Maps link, WhatsApp number for RSVP).
Personal links: /?to=Priya   and   /?to=Priya&lang=ta  (Tamil)
